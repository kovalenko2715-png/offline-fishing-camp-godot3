# Offline Fishing Camp for Android

Офлайн-прототип рыбалки в **Godot 3.5/GLES2**.

## Текущая версия

- Сенсорный джойстик.
- Озеро и пляж.
- Палатка, стол, костёр, магазин и стойка удочек.
- Девять плавательных рыб.
- Заброс удочки, улов и монеты.
- Export preset для ARM64 и ARMv7.
- Загрузчик готовых локальных GLB/DAE-моделей с офлайн-резервной процедурной графикой.

## Интеграция ассетов

Карта моделей находится в `assets/manifest.json`. Лицензионные требования описаны в `assets/licenses/README.md`.

Перед публикацией в проект добавляются только модели с проверенной индивидуальной лицензией. Ассет не должен зависеть от сети во время запуска и игры.

## Запуск

1. Установить Godot 3.5 или совместимый Godot 3.x.
2. Открыть `project.godot`.
3. Запустить `Main.tscn`.

## Сборка APK

1. Установить Android export templates для Godot 3.
2. Настроить Android SDK/JDK в редакторе.
3. Выбрать preset `Android`.
4. Экспортировать `build/OfflineFishing.apk`.
