# 3D-ферма

Проект переориентирован с рыбалки на фермерскую игру для Godot 4.

## Игровой цикл

- Управление персонажем: WASD или стрелки.
- Рядом с одной из четырёх грядок посадите семена, полейте их и дождитесь созревания.
- Соберите пшеницу и продайте её: получите монеты и новые семена.
- Сохранение экономики и состояния грядок — `user://farm_save.json`.

## Визуальные ресурсы

Используются только внешние готовые модели. Визуальные примитивы и программно созданные модели запрещены. Список источников, ожидаемые пути, лицензирование и инструкция импорта: [`assets/README.md`](assets/README.md).

**Важно:** бинарные модели пока не добавлены, поэтому визуальная сцена фермы не завершена. Нужен `assets/models/farm/farm_scene.glb`, собранный из лицензированных моделей; при его отсутствии игра явно показывает предупреждение и не рисует примитивную замену.

Откройте `project.godot` в Godot 4 и запустите главную сцену.
