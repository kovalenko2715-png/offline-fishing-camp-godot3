# Рыбалка у озера — Godot 3

Стартовый репозиторий офлайн 3D-игры для Android-смартфона.

## План прототипа

- Небольшая зона отдыха у озера: палатка, стол, костёр и лавка/магазин снастей.
- Рыбалка с удочкой, поклёвкой и вываживанием.
- Несколько видов рыб с готовыми 3D-моделями.
- Сенсорное управление и локальное сохранение прогресса.
- Все игровые ресурсы включаются в сборку; интернет во время игры не нужен.

## Ресурсы

Список кандидатов, требования к лицензиям и статус загрузок находятся в [ASSETS.md](ASSETS.md). Модели должны быть локально включены в проект; внешние ссылки не используются игрой при запуске.

## Сборка

После добавления исходников проекта открыть `project.godot` в Godot 3 и экспортировать Android APK через Android export template. Для сборки нужны Android SDK/JDK и настроенный Android export preset. На этом этапе проектный каркас и сами игровые ассеты ещё не добавлены.
