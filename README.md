# Offline RPG Camp

Офлайн-мобильный прототип 3D-RPG на актуальном Godot 4 с touch-управлением.

## MVP

- Сенсорный джойстик для Android.
- Сбор дерева и камней.
- Квест сбора ресурсов.
- Палатка восстанавливает тепло.
- Магазин продаёт предметы.
- Локальное сохранение в `user://save.json`.
- Полностью офлайн-базовая логика.

## Структура сцены

- палатка;
- стол крафта;
- костёр;
- магазин;
- озеро;
- деревья и камни;
- сенсорные кнопки и джойстик.

## Запуск

1. Установить актуальную стабильную версию Godot 4.
2. Открыть каталог проекта через `project.godot`.
3. Запустить `Main.tscn`.

## Android

Экспортировать через Android preset/ARM64 с использованием GL Compatibility для широкой совместимости устройств.
